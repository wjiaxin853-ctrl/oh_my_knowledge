# JupyterLab服务器
### 配置pycharm

终端启动
```
jupyter lab
```


1. 打开你的 `.ipynb` 文件

2. 顶部 Jupyter 服务器下拉框 → **Configure Jupyter Server**JetBrains

3. 选择【Use Managed Server】

4. 取消勾选 `Autodetected execution mode`

5.**Execution mode：选择 JupyterLab**JetBrains

6. 命令行参数填入：

plaintext

```
--ip=127.0.0.1 --port=8888 --no-browser
```

7. 确定保存。打开 ipynb，pycharm 会自动拉起 jupyter‑lab 服务，不需要你手动敲命令行启动。
