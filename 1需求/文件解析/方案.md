## 模块一：判断文件类型

文件类型尾缀，文件的结构（看是不是压缩包，还是二进制），magic头

常见类型文件：

| 文件类型 | 扩展名        | Magic Header (Hex)      | 备注          |
| ---- | ---------- | ----------------------- | ----------- |
| JPEG | .jpg .jpeg | FF D8 FF                | 图片          |
| PNG  | .png       | 89 50 4E 47 0D 0A 1A 0A | 图片          |
| PDF  | .pdf       | 25 50 44 46             | `%PDF`      |
| ZIP  | .zip       | 50 4B 03 04             | 压缩包         |
| 7Z   | .7z        | 37 7A BC AF 27 1C       | 压缩包         |
| GZIP | .gz        | 1F 8B                   | 压缩包         |
| TAR  | .tar       | 无固定Magic                | 需检查 `ustar` |
| DOC  | .doc       | D0 CF 11 E0 A1 B1 1A E1 | Office 2003 |
| XLS  | .xls       | D0 CF 11 E0 A1 B1 1A E1 | Office 2003 |
| PPT  | .ppt       | D0 CF 11 E0 A1 B1 1A E1 | Office 2003 |
| DOCX | .docx      | 50 4B 03 04             | OpenXML     |
| XLSX | .xlsx      | 50 4B 03 04             | OpenXML     |
| PPTX | .pptx      | 50 4B 03 04             | OpenXML     |
| MP3  | .mp3       | 49 44 33（常见）            | ID3 Tag     |
| MP4  | .mp4       | 00 00 00 ?? 66 74 79 70 | ftyp        |

字符流文件：

| 文件类型     | 扩展名        | Magic Header |
| -------- | ---------- | ------------ |
| TXT      | .txt       | 无            |
| CSV      | .csv       | 无            |
| JSON     | .json      | 无            |
| XML      | .xml       | 无            |
| YAML     | .yaml .yml | 无            |
| Markdown | .md        | 无            |
| Log      | .log       | 无            |
| Config   | .conf      | 无            |
