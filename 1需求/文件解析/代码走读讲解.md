### libredwg的竞争

我们把 **LibreDWG 这个非线程安全的 C 库，用** **ctypes** **直接加载进了 Python 进程** ✗，而解析是**6 线程池并发**的 ✓ → **两个线程同时进** **dwg2dxf_convert** **→ C 库内部段错误 → 内核直接杀掉整个进程** ✗ → k8s 重启容器（exitCode=139    

 ✓）。C 层崩溃**写不出 traceback** ✗，所以日志"戛然而止" ✓

 **为什么这一步会"点死整个服务"**                                                                                                                                                                                     

 - libredwg.so 是 **50MB 的 C 库** ✓，ctypes.CDLL() 把它加载**进本进程** ✓ 然后直接调 C 函数 ✓ → **C 崩 = 进程死** ✗（Python 的 try/except **拦不住信号** ✓）。                                                                   

 - 对比：**同一函数里** ezdxf 渲染走的是 subprocess ✓ → 子进程崩了只报错 ✓，进程不死 ✓ —— 所以**只有 libredwg 这一步具备"点死 pod"的能力** ✓✓。                                                                           

 - 而它又是在 max_workers=6 的线程池里被并发调用 ✓ → 竞态必现 ✓。

### ABC含义
  

 **①** **ABC** **是什么意思**                                                                                                                                                                                                 

 ABC 就是标准库 abc.ABC，即 class X(metaclass=ABCMeta) 的简写糖。它的作用只有一个：**让** **@abstractmethod** **真的被读**。                                                                                                  

 机制（很短）：@abstractmethod 只是给方法打个记号（__isabstractmethod__=True）；**只有** **ABCMeta** **这个元类会去读它** —— 在类创建时收集所有带记号的方法名放进                                                             

 cls.__abstractmethods__，实例化时如果这个集合非空就拒绝。所以：                                                                                                                                                  

 ```text                                                                                                                                                                                                          

   ① 不继承 ABC（默认元类 type）：没有 __abstractmethods__ → 忘了实现照样实例化（装饰器 = 空写）                                                                                                                  

   ② 继承 ABC                  ：__abstractmethods__ = frozenset({'f'}) → 忘了实现当场 TypeError                                                                                                                  

                                 实现了 → 集合变空 → 正常实例化
