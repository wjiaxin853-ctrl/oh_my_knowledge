# 判断环境是否升级加密
kubectl get configmap -n dsp dsp-apollo-api-env-ps -o yaml
直接查看这个apollo的pulsar的tocken，如果是xxx.yyy.zzz格式，就是JWT明文，说明没有加密注入，反之就是加密了
# 加密原理

中间件以密文的方式注入每个业务pod的configmap，业务代码读取密文的环境变量，并使用解密SDK与密钥去解密。

密钥固定挂载在pod的路径：/etc/middleware-encrypt-keys/key0

# 解密方式

中间件加密支持双secrect，明文还有密文都存储在k8s的secrect中，同一个变量增加后缀encrypt就是加密的部分。

## 方式1:直接从secrect读取明文
例如获取pulsar

查看有哪些secrect
```
kubectl get secret -A
```

查看哪些secrect挂载
```
kubectl get secret -A | grep pulsar
```

获取pulsar明文

```
kubectl get secret -n pulsar pulsar-token-admin -o jsonpath='{.data.root}' | base64 -d
```

获取pulsar密文
```
kubectl get secret -n pulsar pulsar-token-admin-encrypted -o jsonpath='{.data.root}' | base64 -d
```



## 方式2:直接去apollo这个pod去调用包去解密密文

例如获取pulsar的密码

```

```
![[截屏2026-05-23 18.57.48.png]]

$POD选择apollo的pod名字

```
kubectl exec -i -n dsp "$POD" -- python3 - <<'PY'
from dsp_secret import init_from_dir, decrypt_password
import os

key_dir = os.environ.get("MIDDLEWARE_ENCRYPT_KEY_DIR", "/etc/middleware-encrypt-keys")
ciphertext = os.environ.get("PS_TOKEN")

print("KEY_DIR =", key_dir)
print("ENV_PS_TOKEN =", ciphertext)

init_from_dir(key_dir)
print("DECRYPTED_PS_TOKEN =", decrypt_password(ciphertext))
PY
```
