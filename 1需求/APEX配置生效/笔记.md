
### 配置生效流程

```
  1. 配置定义位置

  - values.yaml: D:\DSP\dsp\riskVisualizationServer\scripts\chart\values.yaml 第 32 行
  config:
    prefix: "/apex/connector"

  2. 配置注入位置

  - env-config.yaml: D:\DSP\dsp\riskVisualizationServer\scripts\chart\templates\env-config.yaml 第 8 行     
    - 通过 Kubernetes ConfigMap 将 config.prefix 转换为环境变量 CONFIG_PREFIX
  CONFIG_PREFIX: {{ .Values.config.prefix | quote }}

  3. 环境变量读取位置

  - cfg_lib.py: D:\DSP\dsp\data_channel\dsc_models\__cfg_lib__.py 第 350-354 行
  @property
  def prefix(self) -> str:
      default_value = "/apex/connector"
      if is_debug_mode():
          return default_value
      return os.environ.get('CONFIG_PREFIX', default_value)

  4. 配置实际使用位置

  - client.py: D:\DSP\dsp\data_channel\dsc_client\config\client.py 第 68-69 行
  if ConfigCfg.prefix:
      etcd_cfg.update({"prefix": ConfigCfg.prefix})
    - 这个 prefix 用于配置 etcd 客户端，作为 etcd 中配置数据的键前缀
```
