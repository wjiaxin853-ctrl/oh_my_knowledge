##### 1.ReAct 循环中，累计缓存读取量随轮数近似二次方增长。如何降低这种增长？

![[截屏2026-10-15 19.31.59.png]]

优化方法：

推荐方法：上下文压缩 + 工具输出裁剪 + 缓存复用。
![[截屏2026-10-15 19.34.55.png]]

举例：
```
流水线日志输出：
pytest 运行日志 8000 行
        ↓
Harness 解析结果
        ↓
保留：
- 流水线环境
- 失败测试名称
- 关键错误堆栈（一些流水线脚本就把关键日志最后重新输出一下：镜像包号等）
- 失败文件和行号
- 必要的上下文
        ↓
LLM 继续推理
```
