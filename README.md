# Oh My Knowledge 📚

> 一个持续整理中的个人知识库：记录学习过程、沉淀技术笔记，并把大语言模型（LLM）的概念、原理和实践串联起来。

目前仓库主要聚焦 **大语言模型（LLM）**，内容包括基础概念、Transformer、训练与微调、推理、模型评估、幻觉问题、MiniMind 项目及经典论文阅读笔记。笔记以学习与实践记录为主，会持续补充和调整。

## 🛠️ 如何使用

- **按主题查阅**：从上方知识地图进入对应笔记。
- **按路径学习**：参考推荐阅读顺序逐步阅读，并结合 Markdown 笔记和 Jupyter Notebook。
- **本地阅读**：克隆仓库后，使用支持 Markdown 的编辑器打开笔记；`.ipynb` 文件可在 Jupyter 等兼容环境中查看。
- **运行实验前**：先查看对应 Notebook 中的依赖、数据与运行环境要求；不同实验可能需要不同的配置。

```bash
git clone https://github.com/wjiaxin853-ctrl/oh_my_knowledge.git
cd oh_my_knowledge
```

## 📝 关于这个知识库

这是一个面向个人学习与知识沉淀的仓库，而非完整课程或可直接部署的软件项目。部分内容属于阶段性理解、实验记录或论文阅读摘要，可能随学习深入而修订。

欢迎从感兴趣的主题开始阅读；如果发现错误或有改进建议，也可以通过 Issue 交流。
