## 👋 欢迎来到我的知识花园

这里是我的 **个人知识库**，也是一个用来记录学习、整理思考、积累经验和保存灵感的地方。

我希望它不只是一个存放笔记的文件夹，而是一张不断延伸的知识地图：从一个问题出发，深入理解背后的原理；从一次实践出发，记录尝试、收获和反思；再把不同领域的知识连接起来。

**这里不会局限于某一种技术或某一个学科。** 目前率先整理的是 **大语言模型（LLM）** 相关内容，未来还会根据我的学习与兴趣，逐步拓展到更多方向。

> 🌱 **知识库不是一次性写完的作品，而是一座持续生长的花园。**  
> 今天记录一个概念，明天完成一次实验，日积月累，让思考留下痕迹。

## 🔖 如何阅读与使用

- **随意探索**：从上方知识地图选择你感兴趣的主题。
- **沿着线索学习**：跟随专题中的笔记、实验和论文，逐步加深理解。
- **本地查看**：使用支持 Markdown 的编辑器阅读 `.md` 文件，使用 Jupyter 等兼容环境查看 `.ipynb` 文件。
- **实验与代码**：运行 Notebook 前，请根据具体内容核对所需依赖、数据和运行环境。

```bash
git clone https://github.com/wjiaxin853-ctrl/oh_my_knowledge.git
cd oh_my_knowledge
```

## 🌱 关于记录

这个知识库保存的是我在不同阶段的理解，不追求一开始就完美，也不保证每篇笔记都是完整教程。

我希望自己能在这里：

- **记录**：把学过的东西用自己的语言重新表达。
- **连接**：发现不同概念、技术和领域之间的联系。
- **实践**：让想法经过实验、验证与复盘。
- **迭代**：保留成长的轨迹，持续修正和完善。

如果你在阅读中发现问题，欢迎通过 [Issues](https://github.com/wjiaxin853-ctrl/oh_my_knowledge/issues) 交流。
