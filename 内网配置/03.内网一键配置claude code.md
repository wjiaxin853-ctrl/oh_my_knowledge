### 配置constrict Cli

##### 安装
```
内网: npm install -g @costrict/cs --registry=http://npm.uedc.sangfor.com.cn:80
外网: npm install -g @costrict/cs --registry=https://registry.npmjs.org
```

##### 配置内网服务器

```
export COSTRICT_BASE_URL=https://shenma.sangfor.com.cn
```
##### 登陆

```
cs auth login
```
