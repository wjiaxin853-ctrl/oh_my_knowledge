# DSP 平台升级后 - 共享GPU重新配置指南

## 背景说明
DSP 平台升级后，路由会被回滚，需要重新执行共享GPU配置脚本，以恢复AI推理能力（操作分类、标签消减等功能）。

---

## 执行步骤

### 1. 配置 DNS 解析（如果未配置）
配置一次之后不用继续配置了
```bash
echo '200.200.24.5 code.sangfor.org' >> /etc/hosts
```

### 2. 1 方式一：下载并执行共享GPU配置脚本

```bash
echo '200.200.24.5 code.sangfor.org' >> /etc/hosts && mkdir -p /home/mock_gpt && cd /home/mock_gpt && curl http://code.sangfor.org/33214/dsp-tools/raw/master/share_gpu/install_script_gpt_pod.sh -o install_script_gpt_pod.sh && bash install_script_gpt_pod.sh 10.87.67.98 30888 develop-DSP3.0.36
```

**参数说明：**
- `10.87.67.113` - 共享GPU服务器IP（部门固定共用GPU环境）
- `30888` - GPU服务端口
- `develop-DSP3.0.33` - 当前集成仓库分支名（根据实际版本调整）

### 2.2 方式二：流水线对接共享GPU

http://devops.sangfor.com/ci/pipeline/333405

### 3. 验证部署状态

#### 3.1 检查 Pod 运行状态
```bash
kubectl get pods -n dsp | grep -E "taskinference|taskdispatch|qualitative"
```

**期望输出：** 所有 Pod 状态为 `Running`

#### 3.2 验证 GPU 配置
```bash
kubectl get pods -ndsp | grep taskinference | awk '{print $1}' | xargs -I {} kubectl exec -n dsp {} -- cat /etc/inner/task_actuator/gpuConfigs.yaml
```

**期望输出：** 配置中 `ipAddress: 10.87.67.113` 和 `port: 30888` 且 `gpuEnable: true`

#### 3.3 检查 Helm Release
```bash
helm list -n dsp | grep -E "taskinference|taskdispatch|qualitative"
```

**期望输出：** 三个服务的 Helm release 状态为 `deployed`

---

## 注意事项

1. **分支名更新**：如果升级到新版本（如 DSP3.0.34），需要将脚本中的 `develop-DSP3.0.33` 修改为对应的分支名
2. **执行时间**：脚本执行大约需要 3-5 分钟，期间会下载镜像并部署 Pod
3. **网络要求**：确保能访问 `code.sangfor.org` 和 `docker.sangfor.com`

## 常见问题

### Q1: 如何取消对接共享GPU？
```bash
curl http://code.sangfor.org/33214/dsp-tools/raw/master/share_gpu/uninstall_script_gpt_pod.sh | bash -s
```

### Q2: 如何查看当前对接的GPU IP？
```bash
kubectl exec -it etcd-etcd-biz-0 -netcd -- etcdctl get /apex/connector/platformAI/openapi
```

### Q3: DNS配置失败怎么办？
多节点部署时，每个节点都需要配置DNS：
```bash
# 在每个节点上执行
ping docker.sangfor.com
echo -e "nameserver 10.8.8.8" >> /etc/resolv.conf
```

Q4:模型平台共享失败？
---
需要重新执行模型平台执行脚本，有更新
```
mkdir -p /home/mock_gpt && cd /home/mock_gpt && curl http://code.sangfor.org/33214/dsp-tools/raw/master/share_gpu/install_script_open_gpt_port.sh | bash -s
```

## 部署的服务清单

执行脚本后，将在 `dsp` 命名空间部署以下服务：

| 服务名称 | 用途 | Pod 名称前缀 |
|---------|------|-------------|
| dspm-taskinference | 任务推理服务 | dspm-taskinference-* |
| dspm-taskdispatch | 任务分发服务 | dspm-taskdispatch-* |
| dsp-risk-qualitative | 风险定性服务 | dsp-risk-qualitative-deploy-* |
