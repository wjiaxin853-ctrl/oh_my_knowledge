### 初始化
##### 启动
```
vllm serve
```
默认启动的是Qwen3-0.6B模型

###### 启动自定义模型

```
# 用 HF 上的模型
vllm serve Qwen/Qwen3-0.6B --max-model-len 8192

# 用本地下载好的模型目录
vllm serve /Users/wjx/models/Qwen3-0.6B --max-model-len 8192
```

### 调用
##### 查看已加载模型
```
curl http://localhost:8000/v1/models
```

#### 聊天
##### 终端启动聊天
```
vllm chat
```
##### curl调用api聊天
/v1/chat/completions需要模版
```
curl http://localhost:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "messages": [{"role": "user", "content": "Hello!"}],
    "max_tokens": 50
  }'
```
/v1/completions 不需模版
```
curl -s http://localhost:8000/v1/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "/Users/wjx/Desktop/modles/wjx/modle1",
    "prompt": "人工智能的发展",
    "max_tokens": 200,
    "temperature": 0.8,
    "top_p": 0.9,
    "repetition_penalty": 1.1
  }'
```
##### 使用python脚本
```
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8000/v1",
    api_key="dummy"  # No auth required for local server
)

response = client.chat.completions.create(
    model="mlx-community/Qwen2.5-0.5B-Instruct-4bit",
    messages=[{"role": "user", "content": "Hello!"}]
)

print(response.choices[0].message.content)
```
