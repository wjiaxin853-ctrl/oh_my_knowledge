# Transformer 三个问题的复现实验

本目录用于配合 `1.Transformers由来.md` 学习 —— 用三个可运行的 Python 脚本，
**亲手复现** Transformer 出现之前技术的三个痛点，直观感受 Self-Attention 带来的改变。

## 三个问题（来自 1.Transformers由来.md）

| # | 问题 | 演示脚本 | 复现方式 |
|---|------|----------|----------|
| ① | **信息遗忘**：早期信息随时间衰减 | `01_信息遗忘.py` | 手写极简 RNN，计算"最终输出对每个输入的敏感度（记忆强度）"，展示指数衰减 |
| ② | **并行效率低**：只能逐词串行处理 | `02_并行效率.py` | 对比"逐词循环"与"整序列一次矩阵乘"的耗时，运算量完全相同 |
| ③ | **长距离依赖弱**：难以捕获全局上下文 | `03_长距离依赖.py` | 在"远距离回忆"任务上真实训练 LSTM vs 自注意力模型，对比准确率 |

## 运行方法

```bash
# 需要 Python 3 + numpy（③ 还需要 torch；画图需要 matplotlib）
python3 01_信息遗忘.py
python3 02_并行效率.py
python3 03_长距离依赖.py   # 训练 10 个模型，约 1~2 分钟
```

每个脚本会：
1. 在终端打印结果表格与结论；
2. 生成一张示意图保存到 `figures/` 目录。

## 建议的学习顺序

1. **先跑 01**：看"记忆强度"曲线如何随距离指数衰减、序列越长忘得越干净
   —— 这就是 RNN 梯度消失，也是"信息遗忘"的数学根源。
2. **再跑 02**：看同样的运算量，逐词串行比整批矩阵乘慢多少倍、差距如何随长度放大
   —— 这就是 RNN 训练慢、长序列更慢的原因。
3. **最后跑 03**：看两个真实训练的小模型，在同一个"远距离回忆"任务上
   —— 噪声一多 LSTM 准确率跌到瞎猜水平，而自注意力不受距离影响
   —— 这就是 Transformer 为什么用 Self-Attention 替代循环结构。

## 复现问题 → Transformer 的解法（对照）

| 老问题 | Transformer 的解法（见文档第二部分） |
|--------|--------------------------------------|
| ① 信息遗忘 | Self-Attention：当前词直接看到所有词，不受距离限制 |
| ② 并行效率低 | 基于矩阵运算，可高度并行，支持 GPU 大规模训练 |
| ③ 长距离依赖弱 | 多层堆叠捕捉复杂语义，实现长文档全局建模 |

## 实验细节说明

- **01**：RNN 权重谱半径固定为 0.9，保证稳定衰减；同时用"数值扰动法"
  （真的改输入看输出变化）验证解析结果，两条曲线几乎重合。
- **02**：串行与并行版浮点运算量（FLOPs）完全相同，差距纯粹来自"能否并行"；
  在 GPU 上矩阵乘由 cuBLAS 优化，差距会更悬殊。
- **03**：任务为"单对远距离回忆"——序列开头给配对 (A→B)，中间塞 m 个噪声词，
  末尾用 A 查询必须回忆出 B；每批数据配对随机重组，模型无法死记硬背，
  必须真正跨过整段噪声，才能测出"长距离依赖"能力。值空间只有 8 个，
  瞎猜基线是 12.5% —— LSTM 跌到该水平即说明信息被彻底遗忘。
