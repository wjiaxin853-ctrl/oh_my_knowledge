##### 防范措施

1.**限制 Agent 能力边界**
给智能体做权限沙箱：**最小权限原则**，智能体不能随意接管系统界面、不能自动提交敏感表单；禁止 Agent 自动绕过身份验证环节，涉及登录、鉴权必须人工确认。

2.训练阶段：安全对齐（RLHF/RLAIF）
训练时加入大量越狱攻击样本做对抗训练，让模型识别各类诱导套路，拒绝输出违规内容。

3.输入侧防护：Prompt 检测
前置安全过滤器，识别伪装诱导话术：角色扮演、讲故事、分段诱导、转义、特殊伪装 prompt，拦截恶意输入。

4.**输出侧安全审查**

模型输出之后，再经过一层安全审核模块，识别密钥、破解信息、违规内容，输出前拦截。

5.**约束系统提示词 (System prompt)**

强系统提示约束：无论用户怎么角色扮演，都不能违反安全规则；限制模型服从 “伪装身份” 类指令。

6.**对抗提示注入**

防范用户输入里夹带系统指令，区分**用户输入**和系统指令，隔离用户 prompt 不能改写底层规则
