##### 分词器
分词器 ≠ 模型权重，分词器就是一个规范，json格式
- `tokenizer.json`:二进制序列化文件（json 格式），里面打包了完整词表、BPE 合并规则、分词算法逻辑

- `tokenizer_config.json`:transformers 库的配置：记录bos_token/eos_token/pad_token、聊天模板chat_template、最大长度等参数

- `special_tokens_map.json`
特殊 token 映射，哪些是特殊符号。很多模型里这个文件内容可以合并进tokenizer_config.json，甚至可以没有，不是 100% 强制必须存在

👉这一套叫**分词器（tokenizer）**，只负责：文本 ↔ token id 互相转换，**没有神经网络参数，不能做推理、不能训练。**

###### Tocken分词与向量化区别
**tocken分词：**
输入：原始字符串文本
```
"I love deep learning"
```
分词器（Llama3 BPE）把文本切为token 片段
```
["I", " love", "deep", " learning"]
```
然后分词器查表，每个 token 对应一个整数 ID
```
"I" → 42 " love" → 1842 "deep" → 7821 " learning" → 9214
```

得到：==input_ids = [42, 1842, 7821, 9214] 这一步叫编码得到 token id 序列==（整数列表），这一步是整数，不是向量

token id 是每个分词器自己内部私有的编号，每个分词器都不同，没有统一规定（因为词表本身是 “数据训练出来” 的，不是人为手写规定）

**向量化**
拿到整数 id 之后，送入模型第一层：**Embedding 层（嵌入层）**
Embedding 里面一张大表：每个 token id 对应一个浮点向量（比如维度 2048）。
```
id=42 → [0.231, -0.512, 0.771, ... , 共2048个浮点数] 
id=1842 → [0.113, 0.224, -0.331, ... ] ……
```
==把每个 id 查表替换成向量，输出形状：==

==`[seq_len, hidden_size]` → `[4, 2048]`==

==这一步才是向量化==

向量化的表是模型权重文件内存好的，分词器不会存向量，预训练微调的时候向量也会更新，向量化查表不是静态不变，是一直在学习改变
