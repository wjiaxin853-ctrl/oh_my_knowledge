### RMSNorm：归一化方法

Root Mean Square Normalization

归一化：一层里数值的“尺度”先压到比较稳定的范围，再送进后面的计算，不然有的值特别大，有的特别小，网络训练时就容易抖、容易炸、梯度不稳定。可以防止梯度爆炸，梯度消失

在深度学习网络里，层数变深，会出现数值不稳定（梯度爆炸/消失）等，不同于传统的层归一化（LayerNorm），特点：均值归一化 + 方差归一化；而RMSNorm只做“尺度归一化”，==不减均值==

$$
y_i = \frac{x_i}{\sqrt{\frac{1}{n} \sum_{j=1}^{n} x_j^2 + \epsilon}} \cdot \gamma_i
$$
大模型选择这个算法的原因：
1.缺少均值，计算更快，
2.适合残差结构

###### 代码原理

```
# 归一化公式  
def norm(self, x):  
    return x * torch.rsqrt(x.pow(2).mean(-1, keepdim=True) + self.eps)  
  
def forward(self, x):  
    return (self.weight * self.norm(x.float())).type_as(x)
```

rsqrt：平方根的倒数

self.weight：就是γi
