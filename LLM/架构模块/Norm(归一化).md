# Layer Norm（层归一化）
### 定义

==每个样本的特征进行归一化==，而不是对整个批次的特征进行归一化，让每层输入保持稳定分布，从而加速收敛、防止梯度爆炸/消失。

### 概念图
![[Pasted image 20261005183149.png]]

- **btz（batch size）**：一次处理多少条样本
- **seq_len**：每条样本有多少个 Token
- **dim**：每个 Token 有多少维特征
- 一个样本：就是seq_len x dim这一层
- 一个小方块是一个特征值

一个样本就是横截面的一层，一个token就是seq_len*dim，这一条；一个样本包含多个token
![[Pasted image 20261005191621.png]]
这里的一层就类似于一个batch的所有样本的一个纬度是一层，沿着纬度方向去归一化
![[Pasted image 20261005184851.png]]

箭头方向：==沿着dim 纬度做归一化==，就是对一个 Token 自己的所有特征维度进行归一化
不是在 `seq × batch` 这一整个平面上做归一化，而是在这个 `seq × batch` 平面上的每一个位置，沿着 dim 方向做归一化。

### 统计量

layer norm的均值方差在训练阶段，推理阶段是完全一样的，每次输入的时候现算的
# Batch Norm（批次归一化）
### 定义
==**在每一层的每一批数据(一个batch里的同一通道)上进行归一化**==

### 概念图
![[Pasted image 20261005183005.png]]
箭头方向：指向 **btz / batch 这个方向**

固定一个位置和一个特征维度，然后跨 Batch 进行归一化

### 统计量
训练阶段的均值方差是动态的，每个bacth不一样，不是全局固定的

推理时，用的是固定的均值方差，不再看当前输入，

# 优略对比
### 稳定性
batch norm计算会不稳定，比如突然这个batch遇到一个很长的句子，之前的都没有这么长，这里按照batch去计算会导致很大，所以会不稳定，

对比layer，他是按照样本去计算的，不同样本的长度不会影响这些，所以稳定一点，
