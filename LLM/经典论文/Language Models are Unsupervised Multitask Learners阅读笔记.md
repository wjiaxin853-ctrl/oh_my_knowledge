
这是OpenAI的GPT-2 的论文，

==只需要训练一个足够大的语言模型去做下一个词预测（next token prediction），它就能在零样本（zero-shot）的情况下，自然地表现出很多下游任务的能力，而不需要任何针对性的微调==

一句话理解：**我们啥都不教它专门做翻译、问答、摘要……只让它狂猜下一个词，结果它自己就学会了做一堆事！**

最炸裂的一点：这些任务他们一个专门的训练数据都没用，全靠“猜下一个词”这个单一任务泛化出来的！

```
**2019年之前的主流做法**：

- 想做翻译 → 专门收集平行语料训练 seq2seq
- 想做分类 → 专门标注成千上万条数据 fine-tune BERT
- 想做问答 → 专门用 SQuAD 数据集训练

**GPT-2 直接打脸**： “你们费那么大劲干嘛？我就训练猜下一个词，模型大了之后，它自己就懂了这些任务！”
```

模型越大 + 数据越多 + 训练越久 → 零样本/少样本能力越强

语言模型的终极潜力，可能主要靠“越大越强”，而不是靠设计多少花里胡哨的任务。
