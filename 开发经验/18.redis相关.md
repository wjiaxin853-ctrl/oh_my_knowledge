### redis理解

可以简单立即为相当于一个数据库，不带是存储到硬盘，而是存储到内存中
### 获取redis账号密码

```
helm get values -n dsp dsp-apollo-api
```

### 更新对应Pod的redia的ConfigMap，让对应redis配置生效

相当于让对应的pod链接到这个redis数据库，给他配置账号密码

##### 方式一：临时测试，直接修改对应pod的ConfigMap，

```
kubectl edit configmap dsp-catalog-env-redis -n dsp
```

修改后需要重启Pod让配置生效

```
 kubectl rollout restart deployment dsp-catalog-deploy -n dsp
```

##### 方式二：更新helm包，重新部署

更新helm包中的values.yaml文件,之后重新helm包部署
