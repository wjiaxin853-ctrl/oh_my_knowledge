# 增加环境变量与查看

### mac的bash终端

例如加入hugface的镜像源
1. 打开终端

2. 输入下面命令直接添加这一行到配置文件：


    ```
    echo 'export HF_ENDPOINT=https://hf-mirror.com' >> ~/.zshrc
    ```

3. 让修改立即生效（不用重启终端）：

    ```
   source ~/.zshrc
    ```

4. 验证是否成功：

```
   echo $HF_ENDPOINT
```
应该输出：https://hf-mirror.com
