
### 远端开启服务：
```
ctx start
```

远端环境会有：http://localhost:19999，在19999端口，我们进行端口转发就可以到本地mac了

### 开放端口

```
kubectl patch globalnetworkpolicy allow-external-ingress --type='json' -p='[{"op":"add","path":"/spec/ingress/0/destination/ports/-","value":30881}]'
```


### 端口转发到本地

```
ssh -N -L 19999:127.0.0.1:19999 admin@10.65.245.95
```
后台转发
```
ssh -f -N -L 19999:127.0.0.1:19999 root@10.74.167.125
```

后台转发模型平台非结构化demo页面

```
ssh -f -N -L 30882:127.0.0.1:30882 -o ExitOnForwardFailure=yes admin@10.87.67.199
```

### 本地访问
本地打开即可
```
http://127.0.0.1:19999
```

本地打开demo
```
http://127.0.0.1:30881/
```
