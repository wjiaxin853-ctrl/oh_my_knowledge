
# Python 3.10.11 安装与配置（Linux）

## 1. 安装编译依赖
```bash
yum install -y gcc gcc-c++ make zlib-devel bzip2-devel readline-devel sqlite-devel openssl-devel libffi-devel
```

## 2. 解压Python源码
```bash
cd /root/
tar -xzf Python-3.10.11.tgz
```

## 3. 配置编译选项
```bash
cd /root/Python-3.10.11
./configure --enable-optimizations --prefix=/usr/local/python3.10
```

## 4. 编译并安装
```bash
make -j$(nproc)
make altinstall
```

## 5. 创建软链接
```bash
ln -sf /usr/local/python3.10/bin/python3 /usr/bin/python3
ln -sf /usr/local/python3.10/bin/pip3 /usr/bin/pip3
```

## 6. 配置pip镜像源
```bash
cat > /etc/pip.conf << 'EOF'
[global]
index-url = http://mirrors.sangfor.org/pypi/simple
extra-index-url = http://mirrors.sangfor.org/sfpypi/simple
trusted-host = mirrors.sangfor.org
disable-pip-version-check = true
timeout = 120
EOF
```

## 7. 验证安装
```bash
python3 --version
pip3 --version
```

## 8. 创建并使用虚拟环境
```bash
# 创建虚拟环境
python3 -m venv myenv

# 激活虚拟环境
source myenv/bin/activate

# 安装包
pip install numpy
```

### 离线环境安装python到whl包

##### 下载whl包

```
python3 -m pip download \
   --dest /Users/wjx/Documents/dsp/unstruct-demo/src \
   --only-binary=:all: \      # 只下载预编译的轮子
   --platform manylinux2014_x86_64 \
   --python-version 310 \
   --implementation cp \
   --abi cp310 \
   --index-url https://pypi.org/simple \
   netCDF4==1.7.2
```

下载后会得到这个netCDF4到whl还有相关依赖的whl，都是whl格式

### 安装whl包

去指定目录安装python包
```
python3 -m pip install --no-index --find-links=/workspace/src netCDF4==1.7.2
```
