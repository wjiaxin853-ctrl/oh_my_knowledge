### 停止一号进程，默认手动启动进程
```
kubectl patch deploy dsp-taskinference -n dsp -p '{"spec": {"template": {"spec": {"containers": [{"name": "dsp-taskinference", "command": ["tail", "-f", "/dev/null"], "args": []}]}}}}'
```

### 查找容器名称

```
docker ps | grep dsp-dev
```

### 查找指定镜像

```
docker images | grep dsp-dev
```

### 删除指定容器

```
docker rm dsp-dev
```

如果无法删除，说明容器在启动，需要先删除

```
docker stop dsp-dev
```
### 检查指定容器状态

```
docker ps | grep dsp-dev
```

### 启动容器

```
docker start dsp-dev
```

### 输出指定容器详细配置（非常长）

```
docker inspect dsp-dev
```

只查看容器关键信息配置

```
docker inspect dsp-dev --format='
容器名称: {{.Name}}
容器ID: {{.Id}}
状态: {{.State.Status}}
运行时间: {{.State.StartedAt}}
镜像: {{.Config.Image}}
IP地址: {{range .NetworkSettings.Networks}}{{.IPAddress}}{{end}}
端口映射: {{range $p, $conf := .NetworkSettings.Ports}}{{$p}} -> {{(index $conf 0).HostPort}} {{end}}
挂载卷: {{range .Mounts}}{{.Source}} -> {{.Destination}} ({{.Type}}){{end}}
'
```

如果输出的ID地址，端口映射是空，证明采用了Host模式`ssh -p 22221 root@localhost`，使用宿主机网络

### 设置挂载卷

```
docker run -v /root/dsp:/root/dsp ...
```

具体参数配置如下：

```
"Source": "/root/dsp",
"Destination": "/root/dsp"
```
### 进入容器
```
docker exec -it dsp-dev bash
```

```
docker exec     # 在运行中的容器内执行命令
-it             # 两个选项：-i（交互式） + -t（分配伪终端）
dsp-dev         # 容器名称（之前用 --name dsp-dev 创建的）
/bin/bash       # 要在容器内执行的命令（启动bash shell）
```

### 内网配置镜像
#### 1.内网可以拉取镜像
##### 内网拉取镜像
拉取cuda的镜像
```
docker pull mirrors.sangfor.com/nvidia/cuda:11.8.0-cudnn8-devel-ubuntu22.04
```

##### 打一个tag
```
docker tag mirrors.sangfor.com/tensorflow/tensorflow:latest-gpu tensorflow/tensorflow:latest-gpu
```

##### 启动容器
让容器使用nvidia的runtime，并且后台常驻。==采用宿主机器的host==
```
  docker run -d \
    --name wjx-vl-text-gpu0 \
    --network host \
    -e NVIDIA_VISIBLE_DEVICES=0 \
    -e NVIDIA_DRIVER_CAPABILITIES=compute,utility \
    --shm-size 16g \
    -v /root/wjx/Paddle-VL:/workspace \
    -w /workspace \
    mirrors.sangfor.com/tensorflow/tensorflow:latest-gpu \
    sleep infinity
```
会输出容器id；
6b9a5e583e0fb719edc980b18e73326fcfb31dbaac6ba51a69035bb75b259cc1

#### 2.内网拉取不到镜像

##### 外网查看是否有镜像
```
docker manifest inspect docker.io/paddlepaddle/paddleocr-vl:latest-nvidia-gpu-offline
```

#### 外网拉取镜像
```
docker pull --platform linux/amd64 ccr-2vdh3abv-pub.cnc.bj.baidubce.com/paddlepaddle/paddleocr-vl:latest-nvidia-gpu-offline
```

##### 外网保存镜像tar包
```
docker save \ ccr-2vdh3abv-pub.cnc.bj.baidubce.com/paddlepaddle/paddleocr-genai-vllm-server:latest-nvidia-gpu-offline \ -o /Users/wjx/Downloads/paddleocr-genai-vllm-server_latest-nvidia-gpu-offline.tar
```
