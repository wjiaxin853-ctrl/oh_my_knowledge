### 环境分析

**VIP: 10.223.1.202**
虚拟IP（Virtual IP）或浮动IP，常用于高可用集群、负载均衡、或外网映射。

**IPMI: 10.223.1.200**
服务器的独立管理端口（BMC/IPMI），
比如远程开机、重启、KVM查看屏幕、BIOS设置、硬件监控
对应的登陆凭证是进入后台查看到完整的硬件状态、电源控制、虚拟媒体挂载、远程KVM等功能

**CPU IP: 10.223.1.201**（进入这个到DSP后台）
主机操作系统后台
Linux命令行、SSH登录服务器本身，跑npu-smi、部署模型等

浏览器输入：https://10.223.1.201/login。   进入DSP平台



### 天数显卡环境

##### 查看显卡型号

```
ixsmi
```

##### 模型平台硬件配置文件

###### 文件路径
```
/etc/hwcfg/hardware.json
```

###### 查看第一个显卡型号

```
jq .gpu[0].model /etc/hwcfg/hardware.json
```

### 持续查看显卡资源占用

```
watch -n 1 nvidia-smi
```
