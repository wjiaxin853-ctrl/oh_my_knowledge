
### 同步与异步

##### 同步

```
import time

def 煮咖啡():
    print("开始煮咖啡...")
    time.sleep(3)          # 模拟煮咖啡要 3 秒
    print("咖啡煮好了！")

def 煎蛋():
    print("开始煎蛋...")
    time.sleep(4)          # 模拟煎蛋要 4 秒
    print("煎蛋好了！")

# 同步执行：必须等一个完成才能做下一个
print("早餐开始啦～")
煮咖啡()
煎蛋()
print("早餐完成，总共用时：", time.time())   # 你会发现总时间 ≈ 7 秒
```

运行结果特点： 总时间 ≈ 3 + 4 = 7 秒（一个接一个，等前一个结束才开始下一个）
##### 异步

```
import asyncio
import time

async def 煮咖啡():
    print("开始煮咖啡...")
    await asyncio.sleep(3)          # 模拟等待，不阻塞线程
    print("咖啡煮好了！")

async def 煎蛋():
    print("开始煎蛋...")
    await asyncio.sleep(4)
    print("煎蛋好了！")

# 异步主函数
async def main():
    print("早餐开始啦～")
    # 同时开始煮咖啡和煎蛋
    await asyncio.gather(煮咖啡(), 煎蛋())
    print("早餐完成，总共用时：", time.time())

# 运行
if __name__ == "__main__":
    start = time.time()
    asyncio.run(main())
    print(f"实际耗时：{time.time() - start:.2f} 秒")

```

运行结果特点： 总时间 ≈ 4 秒（最长的那个任务时间），而不是 7 秒 因为煮咖啡和煎蛋是同时进行的（等待期间可以并行）

### 异常处理
#### 异常捕获：try / except
- try 块的作用是“**尝试执行可能出错的代码**”
- except 块的作用是“**捕获并处理 try 块中发生的异常**”

无论 try 块里发生什么（正常结束、抛异常、return、break、continue），finally 块都一定会执行。

常用于释放资源：关闭文件、解锁、恢复状态

##### 类的方法（成员方法）

###### 定义语法
![[截屏2026-10-08 15.34.53.png]]
###### 1.实例方法（self）
定义时必须传入self作为第一个参数，可以访问实例变量与类变量，只可以通过实例名访问

使用情况：需要用到init的里面的东西的时候，就要用实例。(用的最多)
###### 2.类方法（`@classmethod` 装饰）
定义时必须吧类作为第一个参数，可以访问类变量，可以通过实例名访问或类名访问

使用情况：需要用到类变量的时候，就用这个
###### 3.静态方法（@staticmethod）
不强制传入self或者cls，对实例和类都一无所知，不能访问类变量与实例变量，可以通过实例名或者类名访问

使用情况：
用不到类里面的变量，的时候，就是针对类单纯实现一个功能逻辑，比较独立的时候，用静态方法

###### 示例代码1
```
from pymongo import MongoClient

class MongoHelper:
    # ============ 类变量 ============
    default_uri = "mongodb://localhost:27017"
    default_db = "test"

    def __init__(self, db_name=None, uri=None):
        # ============ 实例变量 ============
        self.uri = uri or self.default_uri
        self.db_name = db_name or self.default_db
        self.client = None
        self.db = None

    # ============ 1. 实例方法 ============
    def connect(self):
        """需要用到 self.uri、self.db_name，所以是实例方法"""
        self.client = MongoClient(self.uri)
        self.db = self.client[self.db_name]
        return self.db

    def insert(self, collection, data):
        """需要用到 self.db，所以是实例方法"""
        return self.db[collection].insert_one(data)

    def find(self, collection, query=None):
        """需要用到 self.db，所以是实例方法"""
        query = query or {}
        return list(self.db[collection].find(query))

    def close(self):
        """需要操作 self.client，所以是实例方法"""
        if self.client:
            self.client.close()

    # ============ 2. 类方法 ============
    @classmethod
    def from_config(cls, config):
        """工厂方法：从配置字典创建实例，用 cls 创建"""
        return cls(db_name=config.get("db"), uri=config.get("uri"))

    @classmethod
    def get_default_uri(cls):
        """只读类变量，用类方法"""
        return cls.default_uri

    # ============ 3. 静态方法 ============
    @staticmethod
    def is_valid_collection_name(name):
        """纯校验：和实例无关"""
        return isinstance(name, str) and len(name) > 0

    @staticmethod
    def build_query(field, value):
        """纯工具：构造查询条件，不需要 self 或 cls"""
        return {field: value}
```

```
class Dog:  
    # 类变量  
    species = "犬科"  
  
    def __init__(self, name):  
        # 实例变量  
        self.name = name  
  
    # 1. 实例方法：需要 self  
    def bark(self):  
        print(f"{self.name} 在叫，属于{self.species}")  
  
    # 2. 类方法：需要 cls  
    @classmethod  
    def get_species(cls):  
        print(f"物种是：{cls.species}")  
  
    # 3. 静态方法：不需要 self 也不需要 cls  
    @staticmethod  
    def info():  
        print("狗是人类的好朋友")  
  
  
d = Dog("旺财")  # 创建对象，并把旺财给到name
  
# 实例方法  
d.bark()              # 旺财 在叫，属于犬科  
Dog.bark(d)           # 通过类名调用，手动传实例  
  
# 类方法  
Dog.get_species()     # 物种是：犬科  
d.get_species()       # 通过实例调用，自动传类  
  
# 静态方法  
Dog.info()            # 狗是人类的好朋友  
d.info()              # 通过实例调用，也不会自动传东西
```

### with

with 语句是 Python 中用于上下文管理的神奇工具，它简化了资源管理（如文件、网络连接、锁等）的代码，确保资源被正确清理，即使在发生异常时也是如此。

基本语法：
```
with context_expression [as target]:
    with-block

```

传统方式：
```
file = None
try:
    file = open('example.txt', 'r')
    content = file.read()
    # 处理内容
finally:
    if file:
        file.close()  # 必须手动关闭
```

使用 with 语句（推荐方式）

```
python
with open('example.txt', 'r') as file:
    content = file.read()
    # 处理内容
# 文件会自动关闭，即使发生异常
```


with的底层实现

```
# with 语句的等价代码
manager = context_expression
target = manager.__enter__()
try:
    with-block
except Exception as e:
    if not manager.__exit__(type(e), e, e.__traceback__):
        raise
else:
    manager.__exit__(None, None, None)

```

### 单例与实例

==单例就是全局只有一个，返回相同的对象，实例就是根据实际去返回不同的对象==

模块级单例就是这个文件只创建着一个对象，其他文件impoet这个模块都是用的着一个单例相同的返回。

代码示例：
##### 实例（每次都是新的）
```
class Pizza:
    def __init__(self, flavor):
        self.flavor = flavor

# 每次调用 Pizza() 都创建一个新对象
p1 = Pizza("夏威夷")
p2 = Pizza("海鲜")
p3 = Pizza("夏威夷")

print(p1 is p2)  # False（不同对象）
print(p1 is p3)  # False（即使口味一样，也是不同对象）
print(p1.flavor) # "夏威夷"
print(p2.flavor) # "海鲜"
print(p3.flavor) # "夏威夷"
```

每次调用都是根据传入的，按照class定义的输出对应的，根据传入的不同返回不同的对象

##### 单例（全局永远只有一个）
```
class SingletonPizzaShop:
    _instance = None
    
    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance
    
    def __init__(self, flavor):
        self.flavor = flavor  # ⚠️ 但这里每次都会被覆盖

# 不管你怎么调用，拿到的都是同一个门店
s1 = SingletonPizzaShop("夏威夷")
s2 = SingletonPizzaShop("海鲜")
s3 = SingletonPizzaShop("芝士")

print(s1 is s2)  # True（同一个对象！）
print(s1 is s3)  # True（还是同一个！）
print(s1.flavor) # "芝士"（最后一次调用覆盖了前面的）
print(s2.flavor) # "芝士"
print(s3.flavor) # "芝士"
```

这里每次传入都会将这个实例：super().__new__(cls)给更新初始化，保证全局唯一，也就是最后一次调用，
