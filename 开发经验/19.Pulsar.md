### Plusar格式

persistent://{tenant}/{namespace}/{topic}

```
  - persistent://10001001/default/dsp-ai-api
      - tenant = 10001001
      - namespace = default
      - topic = dsp-ai-api

  - persistent://collect/default/collect-sta-http-log
      - tenant = collect
      - namespace = default
      - topic = collect-sta-http-log
```
### 查询Plusar有多少个Topic

打开grafana面板的**Explore**，选择数据源Prometheus，输入查询PromQL

```
count(count by (topic) (pulsar_subscription_back_log))
```
当前34版本是有25个topic

### 查看所有topic

#### 设置Pulsar API调用的环境变量

TOKEN是密码，PROXY是地址
```
TOKEN=$(kubectl get secret -n pulsar pulsar-token-admin -o jsonpath='{.data.TOKEN}' | base64 -d)
PROXY="http://pulsar-proxy.pulsar.svc.cluster.local"
```

#### 三个命名空间分别查看topic
##### 10001001/default
```
kubectl exec -n pulsar pulsar-broker-0 -- curl -s "${PROXY}/admin/v2/persistent/10001001/default" \
  -H "Authorization: Bearer ${TOKEN}" | python3 -c "
import sys,json,re
for t in sorted(set(re.sub(r'-partition-\d+$','',t) for t in json.load(sys.stdin))):
    print(t)"
```

##### 10001001/dsp-dataidentify
```
kubectl exec -n pulsar pulsar-broker-0 -- curl -s "${PROXY}/admin/v2/persistent/10001001/dsp-dataidentify" \
```
